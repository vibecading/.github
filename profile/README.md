# VibeCADing

**Vibe CADing for the built and the imagined**

An open innovation lab for AI-native tools in architecture, 3D, games and creative work

Architects, 3D artists and game developers already describe what they want in words. VibeCADing connects those words to the software that does the work: Rhino, Revit, Blender, Unreal, Godot, TouchDesigner and the rest

- [Discussions](https://github.com/orgs/vibecading/discussions): show your work, ask for critique, propose a tool
- [awesome-vibecading](https://github.com/vibecading/awesome-vibecading): a catalog of AI tools for creative software, coming soon
- [vibecading.io](https://vibecading.io)
