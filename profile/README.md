An open innovation lab for AI-native tools in architecture, 3D, games and creative work

Architects, 3D artists and game developers already describe what they want in words. VibeCADing connects those words to the software that does the work: Rhino, Revit, Blender, Unreal, Godot, TouchDesigner and the rest

- [reverse-cad](https://github.com/vibecading/reverse-cad): a building's camera and parametric model from ordinary photos, checked against measured drawings. [Open the studio](https://vibecading.github.io/reverse-cad/studio/)
- [paramgraph](https://github.com/vibecading/paramgraph): a building as a parameter graph in plain text, with diff and three-way merge for git
- [Discussions](https://github.com/orgs/vibecading/discussions): show your work, ask for critique, propose a tool
- [awesome-vibecading](https://github.com/vibecading/awesome-vibecading): a catalog of AI tools for creative software
- [Play](https://vibecading.io/play/): every key is geometry, a game for while your agents build
- [vibecading.io](https://vibecading.io)
